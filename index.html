Programming Projects

Within Time

Main project in development.

Within Time is a TBRPG that I began developing back in 2023 in an effort to create my first commercial game. It then later evolved into being a largescale project, in which I decided to dedicate a large majority of my time to. Within Time is created with the Godot game engine and has been using said engine since January of 2025. The game is directed by me and involves collaborative efforts from my indie team 'Team INNERMINDS', a small company I started alongside the creation of Within Time in order to outsource help so that I would not be creating this game alone. Team INNERMINDS has grown to a size of 8 and also supports a large amount of voice actors working on the project.
